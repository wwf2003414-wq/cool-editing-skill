# 工具与渲染

本技能改编自 [HeyChengC/wallstreet-explainer](https://github.com/HeyChengC/wallstreet-explainer/tree/f39845abd45dab3c9ce62587aa5d02f6afe82612)，保留了原项目的素材、对齐和音频辅助脚本，见随附 MIT 许可。

| 任务 | 可用工具 |
| --- | --- |
| 找片、截取与检查 | `python scripts/footage.py search "查询"`，`get` 下载片段，`sheet` 看联系表，`scenes` 查切点，`wave` 看剪口。需要 FFmpeg、ffprobe、yt-dlp，抽图需 Pillow。 |
| 新闻原文 | `node scripts/snap_news.mjs <jobs.json> [素材 ID …]`。按脚本头部的参数说明准备 URL、关键词与 Playwright，截图写到 jobs.json 旁的 docs/。本机有 Edge 时可设 PLAYWRIGHT_CHANNEL=msedge 使用它。发布前单独检查截图里的画内字、图表和页边。 |
| 对齐 | `python scripts/host_timeline.py <口播.mp4> <script.json> <timeline.json>`。需要 faster-whisper，模型目录可通过 WHISPER_DIR 指定。先确认 script.json 的句子来自当前版本，模型词时刻以实际听感和波形复核。 |
| 配音 | 只有文案时可用 `python scripts/temp_voice.py <script.json>` 生成 edge-tts 临时音轨和时间线。正式音频就绪后用 `--asr` 重新对齐。 |
| 合成 | 原画幅。用 FFmpeg `crop` 取肩到头顶的方形区域，`scale` 到圆窗直径，`geq` 用距圆心的半径生成 alpha，`overlay` 到右上角。原声和圆窗来自同一时间段。可复用 scripts/circle_overlay.py 中的 circle_graph，参数使用源像素裁切区和输出像素位置。图层顺序为勃艮第底、B-roll、圆窗、字幕。 |
| 混音 | 需要混配时用 `python scripts/mix.py <片子目录> --check`，按脚本头部准备 timeline.json 和 sfx.json。只用口播时可直接用 FFmpeg 测量和归一化到约 −14 LUFS，控制真峰值。 |
| 检查 | 用 ffprobe 验证流、画幅和时长，用 FFmpeg 完整解码。看每个 B-roll 的入点、中段、出点，确认头顶肩线、图文安全区、素材内容和口播同步。 |

归档时记下所用素材的原始 URL、署名和许可。未经核实的内容别做成带结论的图表或仿新闻截图。


## 剪映专业版

- 新建本地草稿，使用不同于既有版本的名字。分别保留口播主轨、勃艮第红 B-roll、右上圆窗、字幕和原声轨。
- 圆窗和原声共享源时间码。先制作保留双肩的方形取景素材，再在同一素材内处理圆形边缘和金边。圆窗片段的入出点、缩放及位置关键帧可在剪映里继续调整。
- 保持媒体文件路径稳定。可使用现有草稿生成工具建立时间线，随后在剪映打开草稿，定位到开场和后段的 B-roll，检查素材、圆窗、字幕和同步。根据用户要求决定是否本地导出 MP4。

## 圆窗动效

- 从同一个圆心生成外轮廓和内侧画面，合成一条带 Alpha 的头肩圆窗素材。剪映已实测可将 ProRes 4444 MOV 作为整块圆窗。也可用确认支持透明背景的剪映复合片段。人物、圆形裁切和一圈金边必须只受同一个外层片段的变换，避免分别在金底与人物层上复制关键帧。
- 给全屏到 B-roll 的圆窗设置三个状态。先对齐同期原片中头肩取景的中心，原地把圆窗缩到目标尺寸，再保持该尺寸，用 X/Y 关键帧移到右上角。可用约 0.3 秒缩小、0.35 秒移位起排。素材等圆窗落位后入场，连续换素材时保持圆窗位置。
- 在剪映打开草稿，实际跳到入场首帧、缩放中间、移动中间和落位帧。100% 或放大检查金边是否随人物整体移动，以及是否有大金底、重影、偏心、露底或双线。只比对草稿参数无法验证剪映预览是否应用了关键帧。排版以最大运动范围为准，确保文字留白。

## 两段以上口播与替换素材

- 按叙事确定开场、主体和结尾，用实际台词与波形定位切点。去掉口误、重录和不必要的停顿，保留自然呼吸。在剪映时间线上确认相邻片段无空隙、音频不重叠，试听接点前后并核对字幕起止。
- 收到同一段口播的新版时，从头、中、尾取音频样本与旧版波形比对，并核对帧率、时长及问题区间。同一时间轴才能沿用旧剪口、字幕和 B-roll。发现偏移或删改时重新做源时间映射。全屏口播和圆窗必须引用同一版本。
- 遇到面部抽动，先按剪口换算成片与源片时间码，逐帧比较眼睛、脸颊、嘴型与静态背景。区分源片里的局部突变、时间轴错误和导出后才出现的问题。优先用用户提供的修正版。源片有异常且没有替代素材时，可用能支持当句的证据画面和同步原声覆盖该区间，必要时暂停圆窗。避免未经验证的全片插帧或面部处理。
- 剪映内导出后逐帧检查报错区间和两段口播接点，抽查全屏段和圆窗段。检查纯色或黑帧、时长、分辨率、帧率和全片解码，并试听声画同步。如果本机无法完成剪映导出，交代草稿实测情况与成片实际使用的方式。

## 运行辅助脚本

从技能目录执行表中的命令。按用到的脚本单独安装相应依赖，素材和输出放在项目目录。剪映是本地完成可编辑时间线和原生导出的入口。辅助脚本可用于素材准备、核查与混音。
